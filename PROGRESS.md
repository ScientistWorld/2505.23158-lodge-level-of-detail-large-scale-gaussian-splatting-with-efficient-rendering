# Progress

## Current state (iteration 11, hardening)

- **World:** a large synthetic street canyon, generated by `eval/test/world.py`, which is hidden.
  - Public data in `data/lodge_city/`: the trained base 3DGS model (247,095 Gaussians), cameras, and training/validation images.
  - Hidden: the test cameras and targets (`eval/test/hidden_set.npz`), plus the evaluator's own copy of the base model.
- **Method:** `method/lodge.py` implements LODGE (threshold search, smoothed/pruned/fine-tuned levels, chunks with visibility filtering, two-chunk opacity blending). `scripts/method.sh` reproduces the reference (seed 0, γ = 0.03, s = 0.2). It takes about 8 minutes on one GPU.
- **Evaluation:**
  - `scripts/evaluate_train.sh` (visible) and `scripts/evaluate_test.sh` (hidden) render every `checkpoints/*/representation.npz` themselves.
  - They apply validity, memory budget (0.65·N0), work budget (0.70×), quality-floor and transition gates.
  - They write `scoring/scores_{train,test}.json`.
- **Evidence:** `notes/hardening/`:
  - audit harness, tuning sweep, per-case hidden-test scores, rank analysis;
  - archives of earlier runs (seed-dependent chunks; before the budgets; old view sets).
